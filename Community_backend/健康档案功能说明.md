# 健康档案功能说明

## 🏥 功能概述

健康档案功能允许用户为每个宠物创建详细的健康记录，包括基本信息、驱虫记录、接触史和皮肤病史等，为宠物健康管理提供全面的数据支持。

## 📊 数据库设计

### HealthRecord 模型
- **userId**: 关联用户ID（必需）
- **petId**: 关联宠物ID（必需）
- **weight**: 体重（可选，0-200kg）
- **allergies**: 过敏史（默认"无"，最大500字符）
- **sterilized**: 绝育状态（必需，"是"/"否"）
- **deworming**: 驱虫信息
  - **frequency**: 驱虫频率（必需，"每月"/"每季度"/"偶尔"/"从不"）
  - **lastDate**: 最近驱虫时间（可选）
- **recentContact**: 近期接触史（可选，最大500字符）
- **skinDiseaseHistory**: 既往皮肤病史数组
  - **startDate**: 开始时间（必需）
  - **diseaseName**: 患病名称（必需，最大100字符）
  - **affectedAreas**: 患病部位数组（可选，["背部","腹部","爪缝","面部","全身"]）
  - **symptoms**: 症状表现数组（可选，["掉毛","结痂","渗液","红斑","瘙痒"]）
  - **medication**: 用药信息（可选，最大200字符）
  - **isCured**: 是否治愈（必需，"是"/"否"）
  - **notes**: 备注（可选，最大300字符）
- **status**: 状态（active/deleted）
- **createdAt/updatedAt**: 创建/更新时间

## 🔌 API 接口

### 1. 获取健康档案列表
```
GET /api/health
```
需要认证，返回当前用户所有宠物的健康档案。

### 2. 获取单个宠物的健康档案
```
GET /api/health/:petId
```
需要认证，返回指定宠物的健康档案。

### 3. 创建或更新健康档案
```
POST /api/health/:petId
PUT /api/health/:petId
```
需要认证，创建或更新宠物的健康档案。

**请求体**：
```json
{
  "weight": 25.5,
  "allergies": "无",
  "sterilized": "是",
  "deworming": {
    "frequency": "每月",
    "lastDate": "2024-01-15"
  },
  "recentContact": "上周去过宠物医院",
  "skinDiseaseHistory": [
    {
      "startDate": "2023-06-01",
      "diseaseName": "皮肤过敏",
      "affectedAreas": ["背部", "腹部"],
      "symptoms": ["瘙痒", "红斑"],
      "medication": "抗过敏药",
      "isCured": "是",
      "notes": "已完全治愈"
    }
  ]
}
```

### 4. 删除健康档案
```
DELETE /api/health/:petId
```
需要认证，软删除宠物的健康档案。

### 5. 添加皮肤病史记录
```
POST /api/health/:petId/skin-disease
```
需要认证，为宠物添加新的皮肤病史记录。

### 6. 删除皮肤病史记录
```
DELETE /api/health/:petId/skin-disease/:historyId
```
需要认证，删除指定的皮肤病史记录。

## 🎨 前端功能

### 宠物选择
- 显示用户的所有宠物
- 点击宠物头像选择要查看/编辑的宠物
- 支持宠物头像和基本信息显示

### 健康档案表单
- **体重输入**：数字输入框（单位：kg）
- **过敏史**：多行文本输入（无则填"无"）
- **绝育状态**：单选按钮（是/否）
- **定期驱虫**：
  - 驱虫频率：单选（每月/每季度/偶尔/从不）
  - 最近驱虫时间：日期选择器（当频率不为"从不"时显示）
- **近期接触史**：多行文本输入
- **既往皮肤病史**：关联表单，支持多条记录

### 皮肤病史管理
- **添加记录**：点击"+ 添加记录"按钮
- **编辑记录**：点击现有记录的"编辑"按钮
- **删除记录**：点击现有记录的"删除"按钮
- **记录详情**：
  - 开始时间：日期选择器
  - 患病名称：文本输入
  - 患病部位：多选（背部/腹部/爪缝/面部/全身）
  - 症状表现：多选（掉毛/结痂/渗液/红斑/瘙痒）
  - 用药：文本输入
  - 是否治愈：单选（是/否）
  - 备注：多行文本输入

### 数据验证
- 绝育状态和驱虫频率为必填项
- 皮肤病史中开始时间、患病名称和是否治愈为必填项
- 体重范围：0-200kg
- 文本长度限制

## 🔄 数据同步

### 登录状态
- **已登录**：数据保存到数据库，支持多设备同步
- **未登录**：数据保存到本地存储，仅当前设备可见

### 兼容性处理
- 支持数据库ID和本地ID
- 自动处理日期格式差异
- 皮肤病史数组的完整管理

## 📱 使用流程

1. **选择宠物**：点击宠物头像选择要管理的宠物
2. **填写基本信息**：输入体重、过敏史、绝育状态等
3. **设置驱虫信息**：选择驱虫频率和最近驱虫时间
4. **记录接触史**：填写近期接触史
5. **管理皮肤病史**：添加、编辑或删除皮肤病史记录
6. **保存档案**：点击"保存健康档案"按钮

## 🔧 技术特点

- **关联设计**：健康档案与宠物和用户完全关联
- **软删除**：删除时标记为deleted状态，保留数据
- **数据验证**：前后端双重验证确保数据完整性
- **响应式设计**：适配不同屏幕尺寸
- **错误处理**：完善的错误提示和异常处理
- **性能优化**：索引优化，支持快速查询

## 🎯 应用场景

- **宠物健康管理**：记录宠物的基本健康信息
- **医疗记录**：详细记录皮肤病史和用药情况
- **预防保健**：跟踪驱虫和接触史
- **兽医咨询**：为兽医提供完整的健康档案
- **健康提醒**：基于驱虫频率设置提醒
