# 宠物管理功能说明

## 🐾 功能概述

宠物管理功能允许用户创建、查看、编辑和删除宠物档案，支持完整的宠物信息管理。

## 📊 数据库设计

### Pet 模型
- **userId**: 关联用户ID（必需）
- **name**: 宠物昵称（必需，最大50字符）
- **avatar**: 头像信息（包含url、source、key、imageId）
- **type**: 宠物类型（必需，cat/dog）
- **breed**: 品种（必需，最大50字符）
- **gender**: 性别（必需，male/female）
- **birthDate**: 出生日期（必需）
- **notes**: 备注（可选，最大500字符）
- **status**: 状态（active/deleted）
- **createdAt/updatedAt**: 创建/更新时间

### 虚拟字段
- **age**: 年龄（年）
- **ageInMonths**: 年龄（月）

## 🔌 API 接口

### 1. 获取品种列表
```
GET /api/pets/breeds?type={cat|dog}
```
无需认证，返回对应类型的品种列表。

### 2. 获取宠物列表
```
GET /api/pets
```
需要认证，返回当前用户的所有宠物。

### 3. 获取单个宠物
```
GET /api/pets/:petId
```
需要认证，返回指定宠物的详细信息。

### 4. 创建宠物
```
POST /api/pets
```
需要认证，创建新宠物档案。

**请求体**：
```json
{
  "name": "小白",
  "type": "dog",
  "breed": "金毛寻回犬",
  "gender": "male",
  "birthDate": "2020-01-15",
  "notes": "活泼好动"
}
```

### 5. 更新宠物
```
PUT /api/pets/:petId
```
需要认证，更新宠物信息。

### 6. 删除宠物
```
DELETE /api/pets/:petId
```
需要认证，软删除宠物（标记为deleted状态）。

### 7. 更新宠物头像
```
PUT /api/pets/:petId/avatar
```
需要认证，更新宠物头像。

## 🎨 前端功能

### 宠物列表页面
- 显示所有宠物档案
- 支持点击编辑宠物
- 支持删除宠物
- 显示宠物基本信息（头像、昵称、品种、年龄、性别）

### 宠物表单
- **头像上传**：支持选择图片作为宠物头像
- **昵称输入**：文本输入框
- **类型选择**：猫/狗单选按钮
- **品种选择**：下拉选择器，根据类型动态加载品种列表
- **性别选择**：公/母单选按钮
- **出生日期**：日期选择器
- **备注**：多行文本输入（可选）

### 数据验证
- 昵称、类型、品种、性别、出生日期为必填项
- 出生日期不能是未来日期
- 文本长度限制

## 🔄 数据同步

### 登录状态
- **已登录**：数据保存到数据库，支持多设备同步
- **未登录**：数据保存到本地存储，仅当前设备可见

### 兼容性处理
- 支持数据库ID（_id）和本地ID（id）
- 自动处理头像URL格式差异
- 年龄计算兼容不同数据格式

## 📱 使用流程

1. **添加宠物**：点击"添加宠物"按钮 → 填写表单 → 保存
2. **编辑宠物**：点击宠物卡片 → 修改信息 → 保存
3. **删除宠物**：点击删除按钮 → 确认删除
4. **查看健康记录**：点击健康按钮（功能待开发）

## 🔧 技术特点

- **软删除**：删除宠物时标记为deleted状态，保留数据
- **数据验证**：前后端双重验证确保数据完整性
- **响应式设计**：适配不同屏幕尺寸
- **错误处理**：完善的错误提示和异常处理
- **性能优化**：索引优化，支持快速查询
