# PetDerma Merged (feature-model + qxl-dev community backend)

This package keeps **feature-model** as the WeChat Mini Program base and **replaces its community frontend** with qxl-dev's implementation. It also **includes qxl-dev's Community_backend** server.

## Structure
- `Front_Page/`: WeChat Mini Program from feature-model, with `pages/community` replaced by qxl_dev's and `utils/` & `config/` merged.
- `Community_backend/`: Express + MongoDB backend from qxl_dev.

## Quick Start

### 1) Backend
1. Ensure MongoDB is available (local or connection string).
2. In `Community_backend/`, copy `.env.example` to `.env` if provided (or set env vars):
   - `MONGO_URI=mongodb://localhost:27017/petderma`
   - `JWT_SECRET=change_me`
   - `PORT=3000`
3. Install & run:
   ```
   cd Community_backend
   npm install
   npm run dev
   ```
4. Verify health: `GET http://localhost:3000/health`

### 2) Frontend (WeChat Mini Program)
1. Open `Front_Page/` in WeChat DevTools.
2. Check `Front_Page/config/environment.js` for API base URL:
   - Set `BASE_URL` (or similar) to `http://localhost:3000` to hit the backend above.
3. Build/Preview in DevTools. Community pages should now use the real backend.

### Notes
- Original feature-model community pages were replaced; other modules remain intact.
- Utilities from qxl_dev were merged: `utils/`, `config/` (including `socket.js`, `auth-helper.js`, `image-loader.js`, etc.).
- `app.json` was merged to include community routes if they were missing (see `.bak` backup).

### Troubleshooting
- If login is required, register via `/api/auth/register` (Postman) or the mini program's login flow.
- For image upload features, ensure `uploads/` directory is writable and `multer` config in the backend is unchanged.
- If ports differ, update `Front_Page/config/environment.js` accordingly.
