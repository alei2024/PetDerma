# WebSocket连接超时问题快速修复指南

## 🚨 问题症状
```
WebSocket连接错误: timeout(env: Windows,mp,1.06.2412050; lib: 3.8.10)
```

## ⚡ 快速修复步骤

### 步骤1: 检查微信开发者工具设置
1. 打开微信开发者工具
2. 点击右上角 **"详情"**
3. 在 **"本地设置"** 中确保勾选：
   - ✅ **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**
   - ✅ **"开启调试模式"**

### 步骤2: 确认后端服务器运行
```bash
# 在项目根目录执行
cd Community_backend
npm start
```

**预期输出**：
```
🚀 服务器运行在端口 3000
📱 环境: development
🌐 访问地址: http://localhost:3000
🔌 WebSocket服务已启动
```

### 步骤3: 检查网络连接
在微信开发者工具控制台中查看：
- 是否有 "网络诊断通过" 的日志
- 是否有 "WebSocket连接成功" 的日志
- 是否有任何错误信息

### 步骤4: 使用调试页面
1. 在微信开发者工具中访问：`pages/debug/network-test`
2. 点击 **"开始测试"** 按钮
3. 查看测试结果，确认各项连接状态

## 🔧 常见问题解决

### 问题1: 服务器未启动
**症状**: HTTP连接测试失败
**解决**: 
```bash
cd Community_backend
npm install  # 如果依赖未安装
npm start
```

### 问题2: 微信开发者工具设置问题
**症状**: 请求被阻止
**解决**: 确保勾选"不校验合法域名"

### 问题3: 端口被占用
**症状**: 服务器启动失败
**解决**: 
```bash
# 检查端口占用
netstat -an | findstr :3000
# 如果被占用，杀死进程或更换端口
```

### 问题4: 防火墙阻止连接
**症状**: 连接超时
**解决**: 临时关闭防火墙或添加例外规则

## 🚀 高级解决方案

### 方案1: 增加超时时间
如果网络较慢，可以修改超时设置：
```javascript
// Front_Page/utils/socket.js
timeout: 60000, // 增加到60秒
```

### 方案2: 使用IP地址替代localhost
如果localhost有问题，尝试使用本机IP：
```javascript
// Front_Page/app.js
baseUrl: "http://192.168.1.100:3000", // 替换为您的实际IP
```

### 方案3: 检查网络代理
如果使用代理，确保代理设置正确：
1. 检查系统代理设置
2. 检查微信开发者工具代理设置
3. 尝试关闭代理测试
