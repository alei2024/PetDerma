# 用户页面设计说明

## 设计概述
按照提供的图片样式，重新设计了用户页面，采用蓝色渐变背景（上蓝下白），与主题色#A5D7E8保持一致。

## 主要功能区域

### 1. 用户头像栏
- **头像显示**：支持点击更换头像
- **用户信息**：显示用户名和用户ID
- **铲屎官主页**：橙色按钮，点击可跳转（功能开发中）
- **切换账号**：右上角按钮，支持账号切换

### 2. 统计数据区域
- **宠物数量**：显示已添加的宠物数量
- **记录数量**：显示健康记录数量
- **提醒数量**：显示提醒数量
- 数据实时更新，从本地存储读取

### 3. 爪爪健康计划
- **计划标题**：显示"爪爪健康"（原囤货计划）
- **星级显示**：4个星星表示进度
- **功能列表**：
  - 宠物管理：日历图标，显示连续管理天数
  - 健康档案：小鱼图标，显示记录进度
  - 当前诊断：医院图标，显示可用诊断次数

### 4. 常用功能区域
- **家庭**：房屋图标
- **客服反馈**：耳机图标
- **消息**：对话气泡图标
- **养宠知识**：书本图标

## 技术实现

### 数据结构
```javascript
data: {
  userInfo: {
    avatar: '',
    nickname: '',
    phone: '',
    loginType: '',
    userId: ''
  },
  statistics: {
    petCount: 0,
    recordCount: 0,
    reminderCount: 0
  }
}
```

### 核心方法
- `loadStatistics()`: 加载统计数据
- `switchAccount()`: 切换账号功能
- `navigateToHomepage()`: 跳转铲屎官主页
- `navigateToDiagnosis()`: 跳转诊断页面

### 样式特点
- **背景渐变**：`linear-gradient(180deg, #A5D7E8 0%, #FFFFFF 100%)`
- **主题色彩**：蓝色系（#A5D7E8, #2C5F7C, #5A8BA8）
- **强调色彩**：橙色（#FFB84D）用于按钮和图标
- **卡片设计**：圆角白色卡片，带阴影效果
- **交互反馈**：点击缩放效果

## 用户体验
- 清晰的视觉层次
- 直观的功能布局
- 流畅的交互动画
- 一致的设计语言

## 扩展性
- 支持动态数据更新
- 易于添加新功能
- 模块化设计便于维护
