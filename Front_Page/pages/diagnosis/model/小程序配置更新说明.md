# 小程序配置更新说明

## 1. 替换模型服务文件

将 `pages/diagnosis/diagnosis.js` 中的引用从模拟服务改为真实API服务：

```javascript
// 原来的代码
const modelService = require('./model/modelService.js');

// 改为
const modelService = require('./model/modelService_real.js');
```

## 2. 更新API配置

在 `pages/diagnosis/model/modelService_real.js` 中更新API地址：

```javascript
const API_CONFIG = {
  // 替换为您的实际服务器地址
  BASE_URL: 'https://your-domain.com/api',  // 修改这里
  ENDPOINTS: {
    SINGLE_PREDICT: '/predict',
    MULTIPLE_PREDICT: '/predict_multiple',
    HEALTH_CHECK: '/health'
  }
};
```

## 3. 配置小程序域名白名单

1. 登录微信小程序后台
2. 进入"开发" -> "开发管理" -> "开发设置"
3. 在"服务器域名"中添加：
   - `https://your-domain.com` (request合法域名)
   - `https://your-domain.com` (uploadFile合法域名)

## 4. 测试配置

使用测试页面验证API调用是否正常：

1. 进入测试页面：`/pages/diagnosis/test/test`
2. 选择测试图片
3. 点击"开始测试"
4. 查看控制台日志确认请求成功

## 5. 错误处理

如果遇到问题，检查以下几点：

1. **网络请求失败**
   - 检查域名白名单配置
   - 确认服务器地址正确
   - 检查HTTPS证书

2. **API调用失败**
   - 检查服务器是否正常运行
   - 查看服务器日志
   - 确认API接口路径正确

3. **预测结果异常**
   - 检查模型文件是否正确加载
   - 确认图片格式和大小
   - 查看服务器错误日志

## 6. 性能优化建议

1. **图片压缩**
   ```javascript
   // 在chooseImage时压缩图片
   wx.chooseMedia({
     count: remainingCount,
     mediaType: ['image'],
     sourceType: ['album', 'camera'],
     sizeType: ['compressed'], // 添加这行
     success: function(res) {
       // ...
     }
   });
   ```

2. **请求超时设置**
   ```javascript
   // 在uploadFile中设置超时
   wx.uploadFile({
     url: API_CONFIG.BASE_URL + API_CONFIG.ENDPOINTS.SINGLE_PREDICT,
     filePath: filePath,
     name: 'image',
     timeout: 30000, // 30秒超时
     success: (res) => {
       // ...
     }
   });
   ```

3. **缓存预测结果**
   ```javascript
   // 可以缓存相同图片的预测结果
   const cacheKey = `prediction_${imagePath}`;
   const cachedResult = wx.getStorageSync(cacheKey);
   if (cachedResult) {
     return Promise.resolve(cachedResult);
   }
   ```

## 7. 监控和调试

1. **添加详细日志**
   ```javascript
   console.log('API请求开始:', {
     url: API_CONFIG.BASE_URL + API_CONFIG.ENDPOINTS.SINGLE_PREDICT,
     filePath: imagePath,
     timestamp: new Date().toISOString()
   });
   ```

2. **错误统计**
   ```javascript
   // 记录预测失败次数
   const errorCount = wx.getStorageSync('prediction_error_count') || 0;
   wx.setStorageSync('prediction_error_count', errorCount + 1);
   ```

3. **用户反馈**
   ```javascript
   // 在预测失败时提供用户反馈
   wx.showModal({
     title: '预测失败',
     content: '网络连接异常，请检查网络后重试',

   });
   ```
