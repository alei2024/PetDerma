# 模型部署说明

## 1. 服务器端部署

### 方案A：直接部署Python应用

1. **准备服务器环境**
   ```bash
   # 安装Python 3.8+
   sudo apt update
   sudo apt install python3.8 python3-pip
   
   # 安装系统依赖
   sudo apt install libglib2.0-0 libsm6 libxext6 libxrender-dev libgomp1
   ```

2. **上传文件到服务器**
   ```bash
   # 将以下文件上传到服务器
   - server_example.py
   - requirements.txt
   - dog_skin_disease_MobileNetV2.pth
   ```

3. **安装依赖**
   ```bash
   pip3 install -r requirements.txt
   ```

4. **启动服务**
   ```bash
   python3 server_example.py
   ```

### 方案B：使用Docker部署

1. **构建Docker镜像**
   ```bash
   docker build -t pet-disease-model .
   ```

2. **运行容器**
   ```bash
   docker run -p 5000:5000 -v $(pwd)/dog_skin_disease_MobileNetV2.pth:/app/dog_skin_disease_MobileNetV2.pth pet-disease-model
   ```

### 方案C：使用云服务部署

推荐使用以下云服务：
- **阿里云ECS** + 自建服务
- **腾讯云CVM** + 自建服务
- **AWS EC2** + 自建服务
- **Heroku** (免费额度有限)
- **Railway** (推荐，简单易用)

## 2. 配置域名和HTTPS

1. **购买域名**（可选）
2. **配置反向代理**（使用Nginx）
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           proxy_pass http://localhost:5000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```

3. **配置HTTPS**（使用Let's Encrypt）
   ```bash
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com
   ```

## 3. 修改小程序配置

### 3.1 更新API地址

修改 `pages/diagnosis/model/modelService_real.js` 中的API配置：

```javascript
const API_CONFIG = {
  // 替换为您的实际服务器地址
  BASE_URL: 'https://your-domain.com/api',
  ENDPOINTS: {
    SINGLE_PREDICT: '/predict',
    MULTIPLE_PREDICT: '/predict_multiple',
    HEALTH_CHECK: '/health'
  }
};
```

### 3.2 替换modelService.js

将 `pages/diagnosis/diagnosis.js` 中的引用改为：

```javascript
// 将这行
const modelService = require('./model/modelService.js');

// 改为
const modelService = require('./model/modelService_real.js');
```

### 3.3 配置小程序域名白名单

在微信小程序后台配置服务器域名：
1. 登录微信小程序后台
2. 进入"开发" -> "开发管理" -> "开发设置"
3. 在"服务器域名"中添加您的API域名

## 5. 性能优化

### 5.1 服务器端优化

```python
# 使用Gunicorn部署
gunicorn -w 4 -b 0.0.0.0:5000 server_example:app

# 或使用uWSGI
pip install uwsgi
uwsgi --http :5000 --wsgi-file server_example.py --callable app
```

### 5.2 缓存优化

```python
from flask_caching import Cache

cache = Cache(app, config={'CACHE_TYPE': 'simple'})

@cache.memoize(timeout=300)  # 缓存5分钟
def load_model():
    # 模型加载代码
    pass
```

### 5.3 负载均衡

使用Nginx进行负载均衡：

```nginx
upstream model_servers {
    server 127.0.0.1:5000;
    server 127.0.0.1:5001;
    server 127.0.0.1:5002;
}

server {
    location /api/ {
        proxy_pass http://model_servers;
    }
}
```

### 6.2 健康检查

定期检查服务状态：

```bash
# 创建监控脚本
#!/bin/bash
response=$(curl -s -o /dev/null -w "%{http_code}" https://your-domain.com/api/health)
if [ $response != "200" ]; then
    echo "Service is down, restarting..."
    # 重启服务
fi
```

## 9. 故障排除

### 常见问题

1. **模型加载失败**
   - 检查模型文件路径
   - 确认PyTorch版本兼容性

2. **内存不足**
   - 增加服务器内存
   - 优化模型加载方式

3. **请求超时**
   - 增加超时时间
   - 优化预测速度

4. **跨域问题**
   - 配置CORS
   - 检查域名白名单
