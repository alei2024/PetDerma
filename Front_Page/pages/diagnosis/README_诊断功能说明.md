# 宠物皮肤病智能诊断功能说明

## 功能概述

本诊断功能集成了训练好的MobileNetV2模型，可以对宠物皮肤病进行智能分类诊断。支持6种皮肤病类型的识别：

- **皮炎 (Dermatitis)** - 皮肤炎症
- **真菌感染 (Fungal_infections)** - 由真菌引起的皮肤病
- **健康 (Healthy)** - 皮肤状态正常
- **过敏反应 (Hypersensitivity)** - 过敏引起的皮肤问题
- **蠕形螨病 (demodicosis)** - 由蠕形螨引起的皮肤病
- **癣病 (ringworm)** - 传染性真菌皮肤病

## 主要功能

### 1. 智能诊断流程

1. **选择宠物** - 用户选择要诊断的宠物
2. **上传图片** - 上传1-9张患处照片
3. **描述症状** - 输入症状描述（可选）
4. **AI分析** - 调用模型进行皮肤病分类
5. **查看结果** - 显示诊断结果和建议

### 2. 模型预测服务 (modelService.js)

- `predictSkinDisease(imagePath)` - 单张图片预测
- `predictMultipleImages(imagePaths)` - 多张图片综合预测
- 支持6种皮肤病类型的分类
- 返回疾病名称、可信度、严重程度、描述和建议

### 3. 诊断结果展示

- **疾病名称** - 中文疾病名称
- **可信度** - 模型预测的可信度百分比
- **严重程度** - 1-5级严重程度指示器
- **疾病描述** - 详细的疾病说明
- **诊疗建议** - 分为居家护理、就医建议、预防措施三个标签

### 4. 智能问诊功能

- 基于诊断结果提供个性化问答
- 支持快捷问题选择
- 模拟AI医生对话

### 5. 模型测试功能

- 单张图片测试
- 多张图片测试
- 测试结果记录和查看
- 用于验证模型预测准确性

## 使用方法

### 基本诊断流程

1. 进入诊断页面
2. 选择要诊断的宠物
3. 点击"上传宠物皮肤照片"选择图片
4. 填写症状描述（可选）
5. 点击"智能诊断"开始分析
6. 查看诊断结果和建议

### 测试模型功能

1. 进入测试页面 (`/pages/diagnosis/test/test`)
2. 选择"单张图片测试"或"多张图片测试"
3. 选择测试图片
4. 查看预测结果
5. 可以清空结果重新测试

## 技术实现

### 模型集成

由于微信小程序无法直接运行PyTorch模型，当前实现使用模拟预测服务。在实际部署中，需要：

1. 将模型部署到服务器端
2. 创建API接口接收图片
3. 返回预测结果
4. 小程序调用API获取结果

### 图片处理

- 支持从相册选择或直接拍照
- 自动调整图片尺寸和格式
- 支持多张图片上传和综合预测

### 数据存储

- 诊断结果可收藏到本地存储
- 支持查看历史诊断记录
- 宠物信息与诊断结果关联

## 注意事项

1. **仅供参考** - 所有诊断结果仅供参考，不能替代专业兽医诊断
2. **图片质量** - 建议上传清晰、光线充足的患处照片
3. **多角度拍摄** - 从多个角度拍摄可提高诊断准确性
4. **及时就医** - 严重症状应及时就医，不要仅依赖AI诊断

## 开发说明

### 修改模型预测逻辑

编辑 `pages/diagnosis/model/modelService.js` 文件中的 `predictSkinDisease` 函数，将模拟预测替换为真实的API调用。

### 添加新的疾病类型

1. 在 `DISEASE_CLASSES` 数组中添加新的疾病类别
2. 在 `DISEASE_NAMES_CN` 对象中添加中文名称
3. 在 `DISEASE_DESCRIPTIONS` 对象中添加疾病描述
4. 在 `getSuggestions` 函数中添加对应的建议

### 自定义建议内容

修改 `getSuggestions` 函数中的建议内容，可以针对不同疾病类型提供更详细的护理建议。
